# CSEC-ASTU Club Landing Page

A modern, responsive landing page designed for the CSEC-ASTU Club — the Cyber Security Club at Adama Science and Technology University. This project was developed as an entry-level web development submission for the club's recruitment process.

🚀 Overview

This landing page serves as a digital gateway for the CSEC-ASTU Club, showcasing the club's mission, activities, and resources. Built with clean, semantic HTML and modular CSS, the design emphasizes readability, visual hierarchy, and mobile responsiveness.

🧩 Features

· Fully Responsive Layout – Optimized for desktops, tablets, and mobile devices
· Modular CSS Structure – Separate stylesheets for maintainability (Landing.css, LandingPageHeader.css)
· Resource Access Section – Quick links to club materials and useful content
· Clean UI – Minimalist design with intuitive navigation
· HTML Form Integration – Includes Form.html for potential member sign-ups or inquiries

🛠️ Tech Stack

· HTML5 – Semantic markup for structure and accessibility
· CSS3 – Custom styling with flexbox and responsive units

📁 Project Structure

```
CSEC-ASTU-Landing-Page/
│
├── Landing.html              # Main landing page
├── Landing.css               # Core styling
├── LandingPageHeader.css     # Header-specific styling
├── Form.html                 # Sign-up / contact form
├── Resources/                # Club resources (files, links, etc.)
└── README.md                 # Project documentation
```
